# CLAUDE.md - NI OSS Health Dashboard (GrimoireLab fork)

This fork of GrimoireLab is the **tool / runtime** for the **NI OSS Ecosystem Health
Dashboard**. The dashboard is built by an AI agent that keeps its memory and goal in a
**separate companion repo**, not here.

## Read-before / write-after (do this every session - principle P6)

1. **Before doing anything**, read the companion context repo:
   `C:/Users/mpetrovi/oss-health-dashboard` (GitHub: MIpetrov-NI/oss-health-dashboard).
   Start with `AGENT.md`, then `docs/{vision,architecture,metrics,roadmap}.md` and
   `knowledge/` as relevant. It is the source of truth for goals and decisions.
2. **After meaningful work**, update it: append to `knowledge/` (reasoning / scaffolds /
   principles / artifacts) and update `docs/` when a decision changes; commit + push there.

## Two-repo boundary (hard rule - principle P7)

- **This fork** holds all tool code, config, panels, deployment - e.g.
  `default-grimoirelab-settings/`, `docker-compose/`, `scripts/`.
- **The companion repo** holds ONLY the agent's context: `docs/` + `knowledge/` +
  `AGENT.md` + `.links.yml`. No tool config there. Never commit collected data or reports
  in either repo (reports go to a separate downstream repo - principle P5).
